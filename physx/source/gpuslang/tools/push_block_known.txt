# push_block_known.txt -- the P9.78 ratchet.
#
# Each line is an entry point whose Slang code reaches only a PREFIX of the
# bytes the bridge pushes for it:
#
#     <cuda kernel name>   <highest byte reached>   <end of the row's last argument>
#
# That is not by itself a defect.  The engine's argument pack is one shape for a
# whole family of kernels, and a port that defers an argument -- a pointer it
# never dereferences, a tolerance the kernel is documented not to use, a
# dynamic-rigid reaction another tranche will add -- legitimately stops early.
# boxBoxNphase.slang says so in the struct itself: `float toleranceLength; //
# @132 (unused by this kernel, present for ABI parity)`, and this file's entry
# for it is exactly `132 136`.
#
# What the list is FOR is that the number stops being assumed.  The RECORDED
# PAIR is checked, not just the name: an entry point that starts reading LESS
# than it used to is a regression, and one that reads more means the line is
# stale and should go.  The list may SHRINK, never grow.
#
# Note what this cannot see: an argument in the MIDDLE of the pack that nothing
# reads.  The measure is a REACH, so a dead argument followed by a live one is
# invisible here -- ps_rigidAttachmentPrepareLaunch's dead `dt` and `isTGS` are
# exactly that, and they do not appear below.
#
